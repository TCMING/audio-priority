# 音频自动切换 · Audio Priority

轻量 macOS 音频输出优先级工具。自动发现设备，拖动排序，自动保存并切换到当前可用的首选输出。

![应用图标](Assets/AppIcon.png)

## 下载安装

到 [Releases](https://github.com/TCMING/audio-priority/releases/latest) 下载 `.dmg` 安装包。

1. 打开 DMG，把“音频自动切换”拖到 **Applications（应用程序）**。
2. 从“应用程序”中打开 App。首次打开自动配置当前用户的登录后台项。
3. 拖动设备列表调整顺序，越靠上越优先，修改自动保存并立即生效。

使用预编译 DMG 无需安装开发工具，也无需运行终端命令。系统可能提示已添加后台项，可在系统设置的“登录项与扩展”中管理。

**兼容性**：当前提供 Apple Silicon ARM64 安装包，最低部署版本为 macOS 13，目前仅在 macOS 27 实测。尚未提供 Intel 版本。

**签名状态**：当前构建采用本地签名，尚未经过 Apple Developer ID 签名和 Apple 公证。首次打开可能被 macOS 拦截。请确认来自本仓库后，按系统“隐私与安全性”中的提示自行决定是否允许。DMG 封装不会消除此类安全提示。

## 自动选择

- 使用 CoreAudio 通知监听设备和默认输出变化，无定时轮询，无网络请求。
- 新设备自动加入末尾，离线设备保留优先级，重新连接后恢复。
- 使用稳定 UID 区分设备，即使名字相同也能分别保存。
- 首次使用沿用当前默认输出优先，其余设备自动追加。
- 同时管理播放输出和系统提示音输出。输入麦克风由系统和各应用管理。
- 首选设备可用时会恢复它，手动选择较低优先级设备也会被恢复。
- 关闭控制窗口后后台继续运行。暂停仅对本次登录生效。

## 更新与卸载

更新时退出控制窗口，把新版拖入“应用程序”替换旧版，打开新版。App 会迁移并重启正在运行的旧后台服务，保留原有设备顺序。

旧名称数组配置会在设备发现时自动迁移。

卸载前，在 App 的“音频自动切换”菜单中选择 **停用并移除登录后台项**，然后删除 App。设备排序配置会保留，再次打开 App 会重新配置后台服务。

## 保存位置

- 排序配置：`~/Library/Application Support/AudioPriority/priorities.json`
- 登录后台项：`~/Library/LaunchAgents/local.audio-priority.plist`

采用进程间文件锁和原子写入，后台监听配置目录变化以立即应用。

## 从源码构建

源码构建需要 Apple Command Line Tools 中的 Swift 编译器。安装预编译 DMG 无需这些工具。

```sh
./build.sh
```

生成 `.build/音频自动切换.app`。构建输出使用隐藏目录，避免测试副本进入常用应用列表。

```sh
./package-dmg.sh
```

生成 `artifacts/AudioPriority-v<版本>-macOS-arm64.dmg` 和 SHA-256 校验文件。打包后自动归档并清理测试 App 与临时挂载内容。
