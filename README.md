# 音频自动切换 · Audio Priority

轻量 macOS 小工具，按自定义优先顺序自动选择可用的声音输出设备。

![应用图标](Assets/AppIcon.png)

例如将设备顺序设为 `WH-1000XM5 → QSN-CBB → Mac mini 扬声器`。耳机连接时选择耳机，耳机断开后选择显示器音频，显示器断开后使用内置扬声器。

## 工作方式

- 监听 CoreAudio 设备与默认输出变化，使用通知触发，无定时轮询。
- 同时切换默认播放输出和系统提示音输出。
- 首选设备可用时，会恢复首选设备。因此手动选择较低优先级设备也会被恢复。
- 输入麦克风由 macOS 和各应用管理。
- 无网络请求。使用音频设备控制接口。
- 登录后自动运行。App 提供设备列表、拖动排序和启用、暂停控制，关闭控制窗口后后台服务继续运行。

## 构建

需要 Mac 和 Apple Command Line Tools（包含 Swift 编译器）。当前构建在 Apple Silicon、macOS 27 上验证，其他系统版本尚未实测。

```sh
./build.sh
```

生成 `build/音频自动切换.app`，内含控制窗口和后台程序。

## 安装

```sh
./install.sh
```

App 安装到当前用户的 `~/Applications`，服务配置保存到 `~/Library/LaunchAgents/local.audio-priority.plist`。安装会接管同名旧服务，已有设备配置会保留。若同名 App 已存在，安装会停止，请先自行备份处理。

这是本地自签名应用，尚未通过 Apple 公证。下载的预编译版可能触发 macOS 安全提示。

## 自定义顺序

打开 App 即可看到输出设备列表，拖动整行调整顺序。越靠上越优先，松开即自动保存并生效。

- 新设备连接后自动追加到末尾，后台运行时也会记住新设备。
- 断开的设备保留在列表中，重新连接时恢复原优先级。
- 每个设备用 CoreAudio UID 标识，同名设备可独立保存。
- 首次安装沿用当前默认输出优先，其余设备自动追加。
- 兼容旧版按名称保存的 JSON 字符串数组，首次检测到设备时迁移。
- 保存采用进程间文件锁及原子写入，后台监听配置目录变化以立即应用。

配置保存在 `~/Library/Application Support/AudioPriority/priorities.json`，由 App 自动管理。`priorities.example.json` 展示旧版输入格式。

查看设备名称与当前输出可以运行以下命令。

```sh
~/Applications/音频自动切换.app/Contents/MacOS/audio-priority --list
```

## 停用与移除

App 的暂停按钮只暂停本次登录。永久停止登录后运行可在终端执行以下命令，然后删除 App 和对应的服务配置文件。

```sh
launchctl bootout "gui/$(id -u)/local.audio-priority"
```

## 验证情况

本机原型后台进程实测约 12 MB 常驻内存，空闲 CPU 为 0.0%。已验证输出被切到较低优先级设备后能自动恢复首选 XM5。资源占用随系统版本和设备而变化。

配置保存后立即切换的集成验证，以及旧配置迁移、拖动排序所用的保存逻辑、同名设备、断开回退、新设备追加的回归测试均已通过。

```sh
./test.sh
```

实际蓝牙重连和显示器拔插仍需在目标设备上测试。
